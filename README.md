# ✊ Rock Paper Scissors

A simple and interactive Rock Paper Scissors game developed to practice web development and game logic. The game is based on the classic hand game in which the player chooses Rock, Paper, or Scissors and competes against the computer.

## Features

- Interactive Rock, Paper, and Scissors gameplay.
- Player selection and computer move.
- Game result based on classic rules.
- Simple and user-friendly interface.
- Practice of conditional logic and event handling.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Learning Outcomes

- Practiced JavaScript conditional statements and functions.
- Learned to handle user interactions and button events.
- Implemented the rules of Rock Paper Scissors.
- Improved understanding of DOM manipulation and frontend development.
